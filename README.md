# My Portfolio + AI Chat Bot

A personal portfolio website inspired by [Josh W. Comeau](https://www.joshwcomeau.com/), built with **React + Vite + Tailwind CSS** and featuring an **AI chat bot** powered by a **Python Flask** backend.

## Quick Start

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate    # Windows
pip install -r requirements.txt
# Create backend/.env with your OPENAI_API_KEY
python app.py
```

## Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS
- **Backend:** Python, Flask, OpenAI API
- **Features:** Dark mode toggle, AI chat widget
